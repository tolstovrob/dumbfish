# Dumbfish

**Dumbfish** &mdash; это UCI-совместимый шахматный движок, написанный на Python.

Несмотря на нелепое название, он реализует оптимизированный однопоточный поиск и трёхфазную ручную оценку.

Сила игры зависит от заданной глубины поиска. На глубине 7 по умолчанию, Dumbfish показывает уровень 1300 Elo (1800 Lichess).

### Архитектура

```
Dumbfish/
├── main.py           # Точка входа
├── uci.py            # Обработчик протокола UCI
├── game.py           # Управление игровым состоянием
├── search.py         # Итеративный поиск
├── score.py          # Оценка позиции (HCE)
├── tt.py             # Транспозиционная таблица с хешированием Zobrist
├── pst.py            # Таблицы PST и данные для оценки
├── config.py         # Конфигурация движка
└── requirements.txt  # Зависимости
```

### Установка

Для запуска необходимо иметь виртуальное окружение Python версии 3.8+. В терминале выполните:

```bash
git clone https://github.com/tolstovrob/dumbfish
cd dumbfish
pip install -r requirements.txt
python main.py
```

Будет запущен UCI-цикл
